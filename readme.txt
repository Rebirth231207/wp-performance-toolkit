A developer-first, zero-overhead performance optimization and diagnostics suite for WordPress.

== Description ==

WP Performance Toolkit is built using the VibeCoding methodology: pure code, zero heavy frameworks, and surgical precision. It provides deep insights and automated optimizations to improve Core Web Vitals, specifically targeting TTFB, LCP, and TBT.

Unlike bloated "all-in-one" plugins, this toolkit is modular and focuses on lean execution.

== Installation ==

1. Upload the `wp-performance-toolkit` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to the 'Performance' menu in the admin dashboard to view real-time telemetry.

== Frequently Asked Questions ==

= Does this plugin use jQuery? =
No. The entire toolkit is built with Vanilla JS (ES6) and pure PHP to ensure zero overhead.

= Is it compatible with PHP 8.3? =
Yes. The plugin is fully optimized for PHP 8.0 through 8.3, utilizing strict typing and modern engine optimizations.
